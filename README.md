# LogSentry: Brute-force Login Detector

## Week 1 - Reading and Parsing Log Files

### Project Description

LogSentry is a Python-based authentication log parser.
It reads login records and extracts timestamp, username,
IP address and login status.

### Features

- Reads authentication log files.
- Extracts information using Regular Expressions.
- Stores records using Python dictionaries.
- Counts successful and failed logins.
- Handles invalid log lines.

### Technologies

- Python
- Regular Expressions
- File Handling

### Legal and Ethical Note

Only analyse logs from systems you own or have
written permission to use.

This project uses generated sample logs only.

### How to Run

1. Install Python.
2. Open the project folder.
3. Run:

python logsentry.py
